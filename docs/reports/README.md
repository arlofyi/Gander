# Reports

Outputs of autonomous runs, one file per run: `YYYY-MM-DD-preflight.md` (from WP-00) and
`YYYY-MM-DD-overnight-report.md` (template in `../plans/2026-11-01-master-plan.md`, section 8).
Reports are records, not plans: they say what passed, what was deferred and why, and what a human
must do next. Nothing in here is edited after the run that wrote it.
