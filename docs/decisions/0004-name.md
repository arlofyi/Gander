# 0004. Product name: Gander

- Status: Accepted
- Date: 2026-11-01

## Context

"OTG View" was a codename. "OTG" means USB On-The-Go to most Android users, and "View" undersells
Fetch and Stream (see `docs/research/naming.md`). The name should be short, friendly, work in a
sentence ("open it in X"), and avoid any VPN vendor's mark.

Collision check (2026-11-01, web search only):

- An open-source, offline, zero-permission Android file viewer named **Gander** exists
  (github.com/mokshablr/gander, distributed via F-Droid). Same platform, adjacent category, but no
  remote access.
- **Gander Social** (`com.gander.social`) on Google Play, a social app released June 2026.
- GitHub user/org `gander` is taken; `gander-app` was free.
- Domains `gander.app` / `gander.dev` not confirmed; trademark registers not searched.

## Options

1. Gander
2. A two-word form ("Have a Gander", "Gander Remote")
3. Dekko / Shufti (same "have a look" slang)
4. Porthole / Yonder (earlier shortlist)

## Decision

**Gander**, as in "have a gander": a quick look at your files. The owner preferred it over the
alternatives and accepted the collision with the existing Android viewer, since the project is
public and open source.

Brand hooks: a goose mascot/logo; geese honk when someone approaches, which maps onto the
non-negotiable that the host always shows when it is being viewed.

## Consequences

- Rename README, CLAUDE.md and docs from "OTG View" to Gander.
- Search results will be shared with the existing Gander viewer: always pair the name with a
  descriptor ("Gander -- your own files, from your own computer") in store listings and the README.
- Use distinct identifiers: repo `<org>/gander`, Android package not under `com.gander.*`
  (e.g. `fyi.arlo.gander` or `app.gander` once a domain is chosen).
- Still to do before a public release: domain registration and a trademark search in classes 9/42.
